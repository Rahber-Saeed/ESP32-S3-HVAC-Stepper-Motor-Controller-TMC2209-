# ESP32-S3-HVAC-Stepper-Motor-Controller-TMC2209-
A custom PCB designed specifically for HVAC applications. It integrates an ESP32-S3 microcontroller with a TMC2209 silent stepper motor driver to control dampers, valves, or flow control mechanisms. Features include 5V/12V power inputs, flyback diode protection, and user I/O headers.
