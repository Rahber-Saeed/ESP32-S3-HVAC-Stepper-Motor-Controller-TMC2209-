# ESP32-S3-HVAC-Stepper-Motor-Controller-TMC2209-
A custom PCB designed specifically for HVAC applications. It integrates an ESP32-S3 microcontroller with a TMC2209 silent stepper motor driver to control dampers, valves, or flow control mechanisms. Features include 5V/12V power inputs, flyback diode protection, and user I/O headers.
# 🌬️ HVAC Controller Board (ESP32-S3 + TMC2209)

This repository contains the complete hardware design for an **ESP32-S3 based HVAC controller board**. It is designed to drive a stepper motor (e.g., for dampers or valves) using a high-performance TMC2209 silent stepper driver.

The board is built to use widely available development modules, making it easy to prototype, repair, or upgrade.

---

## ✨ Key Features

*   **Main Controller:** ESP32-S3-DEV-KIT-N8R8 (WiFi & Bluetooth enabled).
*   **Motor Driver:** TMC2209 SilentStepStick for smooth and quiet stepper motor operation.
*   **Power Inputs:** 
    *   **12V (VM12V):** Motor power.
    *   **5V:** Logic power for the ESP32-S3 and TMC2209.
*   **Protection Circuitry:**
    *   **Flyback Diodes:** Four 1N5819 Schottky diodes protect the driver from back-EMF generated by the motor coils.
    *   **Fuse:** A 1.5A fuse provides overcurrent protection on the 12V input.
*   **User I/O Control:**
    *   `H1` Header for end stops or limit switches, routed to GPIO3 and GPIO4.
    *   `H2` Header for additional user inputs, routed to GPIO8 and MID (likely MISO).
*   **Clean & Efficient Layout:** Router traces designed for reliable high-current usage.

## 🛠️ Usage & Assembly

1.  **Assembly:** 
    *   Solder the terminal blocks, capacitors, diodes, and fuse onto the main PCB.
    *   Insert & solder the ESP32-S3 Dev Kit along with the TMC2209 Stepper driver into their respective headers.
2.  **Wiring:**
    *   Connect your **12V Power Supply** to the `VM12V` terminal. 
    *   Connect your **5V Logic Supply** to the `5V` terminal.
    *   Connect your **Stepper Motor** to the `MA` and `MB` terminals.
3.  **Programming:**
    *   Use the USB-C port on the ESP32-S3 Dev Kit to upload your firmware.
    *   Use libraries like `TMCStepper` or `AccelStepper` to control the motor.
    *   You can connect limit switches or HVAC sensors to the `H1` and `H2` headers.
